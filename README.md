# 🎮 El Pollo Locco (Canvas Game)

A browser-based game built using HTML5 Canvas and JavaScript.
This project focuses on game logic, rendering, and user interaction without external libraries.

---

## 🚀 Live Demo

👉 [Play the game](https://elpolloloco.benjamin-mahalbasic.de/)

---

## 🎯 Features

* Real-time rendering using HTML Canvas
* Smooth animations with `requestAnimationFrame`
* Collision detection
* Keyboard controls
* Game loop & state management
* Object-oriented game architecture

---

## 🛠️ Technologies

* HTML Canvas
* JavaScript 
* CSS

## 🎮 Controls

* ⬅️ ➡️ Move
* ⬆️ Jump (Spacebar)
* 🟢 Throw bottle (D key)

---

## ⚙️ How It Works

The game uses a custom game loop built with `requestAnimationFrame` to continuously update and render the game state.

The code is structured using object-oriented programming (OOP), separating concerns into reusable classes such as:

* Player
* Enemies
* Projectiles (bottles)
* Game world / logic controller

Core concepts include:

* Object-oriented design (classes & modular structure)
* Object movement and physics
* Collision detection
* Rendering via Canvas
